## Vitral 0.1.6

- When a program does not open, Vitral now finds out why: it reads Wine's log and the program's own logs and recognizes known failures. If a failure has a known fix, Vitral tries it by itself and opens the program again; a fix that does not help is undone, and the one that works stays in the app. If nothing works, or the program needs a newer engine, it tells you why.
- Programs that stay open without a window because of a known failure are closed and fixed the same way.
- Report a Problem…: in the alert, in the library (right-click an app) and when an installation stops. It opens GitHub's form already filled in, with a report you can read and change first; your name, user and Mac's name are left out.
- New known failures and fixes arrive without a new Vitral, in a catalog signed with the same key as updates (only while "Check for updates automatically" is on).
- Before installing, Vitral warns about programs known not to work yet (Paint.NET 5.0 and 5.1, Power BI Desktop), and when an installation stops it shows the likely cause.

## Vitral 0.1.6 (español)

- Cuando un programa no abre, Vitral ahora averigua por qué: lee el registro de Wine y los del propio programa, y reconoce las fallas conocidas. Si una falla tiene un arreglo conocido, Vitral lo prueba solo y vuelve a abrir el programa; el arreglo que no sirve se deshace, y el que funciona queda guardado en la app. Si nada funciona, o el programa necesita un motor más nuevo, te dice por qué.
- Los programas que se quedan abiertos sin ventana por una falla conocida se cierran y se arreglan igual.
- Informar un problema…: en el aviso, en la biblioteca (clic derecho en una app) y cuando una instalación se detiene. Abre el formulario de GitHub ya lleno, con un informe que puedes leer y cambiar antes; tu nombre, tu usuario y el nombre de tu Mac no van.
- Las fallas y arreglos nuevos llegan sin esperar un Vitral nuevo, en un catálogo firmado con la misma llave que las actualizaciones (solo si está activado «Buscar actualizaciones automáticamente»).
- Antes de instalar, Vitral avisa de los programas que se sabe que todavía no funcionan (Paint.NET 5.0 y 5.1, Power BI Desktop), y cuando una instalación se detiene muestra la causa probable.
