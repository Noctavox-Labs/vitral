## Vitral 0.1.1

- Fixes "is damaged and can't be opened" when opening a Windows app made with Vitral 0.1.0 downloaded from GitHub. Each app is now signed as a whole on your Mac, and its Windows lives in Vitral's folder (`~/Library/Application Support/Vitral/Prefixes`). Vitral moves the Windows of the apps you already have the first time it opens; open Vitral before opening them.
- If an app still says it is damaged, macOS remembers the earlier rejection at that location: uninstall it in Vitral and install it again.
- A small "Opening…" window shows while a Windows program starts, also when you open it from Finder or the Dock.

## Vitral 0.1.1 (español)

- Arregla «está dañada y no se puede abrir» al abrir una app de Windows creada con Vitral 0.1.0 descargada de GitHub. Ahora cada app se firma completa en tu Mac, y su Windows vive en la carpeta de Vitral (`~/Library/Application Support/Vitral/Prefixes`). Vitral mueve el Windows de las apps que ya tienes la primera vez que se abre: abre Vitral antes de abrirlas.
- Si una app sigue diciendo que está dañada, macOS recuerda el rechazo anterior en esa ubicación: desinstálala en Vitral e instálala de nuevo.
- Una ventanita de «Abriendo…» aparece mientras arranca un programa de Windows, también si lo abres desde Finder o el Dock.
