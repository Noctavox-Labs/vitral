## Vitral 0.1.4

- Add another program from the same installer at any time: right-click an app in the library → "Add Another Program from the Same Installer" (for example MetaEditor, after installing MetaTrader 5). A card shows "Adding…" until the new app is ready.
- Uninstalling an app that came with others from the same installer offers to remove them too, or only that one (the others keep their files and settings).
- Clearer wording: programs from the same installer "share files and settings".

## Vitral 0.1.4 (español)

- Agregar otro programa del mismo instalador cuando quieras: clic derecho en una app de la biblioteca → «Agregar otro programa del mismo instalador» (por ejemplo MetaEditor, después de instalar MetaTrader 5). Una tarjeta dice «Agregando…» hasta que la app nueva está lista.
- Al desinstalar una app que vino con otras del mismo instalador, Vitral ofrece quitarlas también, o solo esa (las otras conservan sus archivos y ajustes).
- Textos más claros: los programas del mismo instalador «comparten archivos y ajustes».
