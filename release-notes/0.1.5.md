## Vitral 0.1.5

- Force Quit: when a Windows program freezes or won't close, right-click its app in the library → "Force Quit…". It closes the program and everything it left running (Windows programs closed from the Mac's menu wait for the program to answer, so a frozen one never closes). The card shows "Closing…" meanwhile.
- Programs that bring parts of Qt but draw their own windows (Winamp) no longer open at half size.
- The .NET Framework 4.8 bar keeps moving while each Microsoft installer runs, instead of stopping at 25 %.

## Vitral 0.1.5 (español)

- Forzar cierre: si un programa de Windows se congela o no se cierra, clic derecho en su app de la biblioteca → «Forzar cierre…». Cierra el programa y todo lo que dejó abierto (los programas de Windows que se cierran desde el menú de la Mac esperan a que el programa conteste, así que uno congelado nunca se cierra). Mientras, la tarjeta dice «Cerrando…».
- Los programas que traen partes de Qt pero dibujan sus propias ventanas (Winamp) ya no se abren a la mitad de tamaño.
- La barra de .NET Framework 4.8 sigue avanzando mientras corre cada instalador de Microsoft, en vez de quedarse en 25 %.
