## Vitral 0.1.3

- Installs Microsoft's .NET Framework 4.8 when a program needs it (about five minutes, from Microsoft, the first time). Under Wine its installers used to end without installing anything; Greenshot, for example, now installs and runs.
- When an installer brings several programs (MetaTrader 5 and MetaEditor, or a suite), Vitral makes the app for the main one and offers the others; each one you pick becomes its own app on the same Windows. Uninstalling one keeps the Windows the others use.
- Picks the right program when there are several of equal weight (MetaTrader 5 opened its editor).
- Programs that live in the menu bar, with no window (such as Greenshot), now count as open.
- When an installer stops by itself, Vitral shows its own message instead of "no new program found".
- Fixed: programs built on recent .NET (such as Paint.NET's installer) failed with "mscoree.dll not found".

## Vitral 0.1.3 (español)

- Instala .NET Framework 4.8 de Microsoft cuando un programa lo necesita (unos cinco minutos, desde Microsoft, la primera vez). En Wine sus instaladores terminaban sin instalar nada; Greenshot, por ejemplo, ahora se instala y funciona.
- Cuando un instalador trae varios programas (MetaTrader 5 y MetaEditor, o una suite), Vitral crea la app del principal y ofrece los demás; cada uno que elijas queda como su propia app sobre el mismo Windows. Desinstalar una conserva el Windows que usan las otras.
- Elige el programa correcto cuando hay varios con el mismo peso (MetaTrader 5 abría su editor).
- Los programas que viven en la barra de menú, sin ventana (como Greenshot), ahora cuentan como abiertos.
- Cuando un instalador se detiene solo, Vitral muestra su propio mensaje en vez de «no encontré ningún programa nuevo».
- Arreglado: los programas hechos con .NET reciente (como el instalador de Paint.NET) fallaban con «mscoree.dll not found».
